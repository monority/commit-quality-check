# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| < 3.0   | No        |

## Reporting a Vulnerability

Do **not** open a public issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/monority/commit-quality-check/security/advisories/new) or contact the repository owner directly.

Include:

- A description of the vulnerability and its impact
- Steps to reproduce or a proof of concept
- Affected versions

You can expect a first response within 7 days. Fixes are released as patch versions and credited unless you prefer anonymity.
